# 新会话提示词：火柴人代码动画

把下面方框里的整段复制到新会话。技术路线留给新会话自己决定，这里只写经验和效果标准。

```text
我想做一部《咒术回战》新宿决战（五条悟 vs 宿傩）的火柴人代码动画，镜头和节奏参考 NinjaristicNinja 的 MMV《Gojo vs Sukuna | Jujutsu Kaisen x coldrain》。

先读仓库里的 docs/交接说明.md。那是上一个会话做了很多版之后留下的经验，以及我对动作和特效的要求。里面提到的做法只是参考，用什么技术你自己判断。

【原片】
- Google Drive：https://drive.google.com/file/d/1CaDI8u7VDxiBfJ90lkYSPABVc4XLNtJp/view
  可以用 gdown 1CaDI8u7VDxiBfJ90lkYSPABVc4XLNtJp 下载。链接失效就告诉我，我重新传。
- 2560×1440，24 帧，145.8 秒。0–3 秒是片头，约 136.3 秒以后是结尾字幕，这两段不用。
- 以这个 2 分多钟的原版为准，不是 96 秒的加速版。
- 仓库 data/ 里有现成的镜头表、命中时间、眼睛和赫/苍的位置，对节奏和构图时可以用。

【画风】
- 整体是简约的火柴人打斗。
- 颜色来自咒术能量和特效：五条偏蓝青，宿傩偏红；赫是红，苍是蓝，虚式茈是紫。
- 双方靠眼睛的颜色区分，眼睛是这个画风里很重要的元素。
- 主要用代码绘制，可能需要逐帧画。
- 原片有很多脸部和眼睛特写，火柴人画不出脸。这类镜头怎么表现由你设计，先给我看方案。

【动作要求：最重要，标准很严】
- 必须是真的在动。关键姿势之间要有真正的中间动作：肢体按关节转动，有预备、发力、收势，惯性和重量感要可信。
- 不能用整体平移、缩放、变形来冒充动作，我一眼就能看出来。之前有一版就因为"完全是静止画面"被我放弃了。
- 流畅，不卡顿，不漏帧。打斗和高速段落最容易出问题，要逐帧检查。
- 节奏跟原片走：切点、出拳和命中的时机、快慢变化，以及原片里的定格和慢放。
- 命中可以短暂定格，比如 2–3 帧，连击时 1 帧，这样打击感更好。

【特效要求：炫酷，但不违和】
- 特效要跟着主体和镜头的运动走。贴着身体、拳头、眼睛的能量是好的；自己往外乱飘、和画面运动无关的粒子很违和。
- 不要无中生有。原片里没有的东西不要加，比如多出来的球、多出来的画面。
- 眼睛：
  - 我不要横向的长光条（像"激光眼"）、盖住眼睛的大光球、向四周发散的粒子，也不要光突然冒出来。
  - 我喜欢眼睛本身发亮，外面一圈贴边的微光；有张力的时刻，眼里有收着的细碎火焰或火星。
  - 光要随睁眼渐亮；切镜时，上一个镜头的特效要立刻消失。
  - 宿傩有四只眼：两只主眼，下面两只小眼。
- 赫、苍、虚式茈：
  - 最后合一时，就是原片里那两颗球从两侧靠拢、汇合，不要另画绕圈的球。
  - 爆炸要有层次，看得出紫色的光，不能过曝成一片死白。
- 打击：命中闪光、双色冲击帧、冲击波、放射速度线、闪电、火花、震屏、推镜，这些我都认可。连击时要减弱，不要每一下都满强度。
- 特效太少我会觉得没劲，位置或运动不对我会觉得违和、丑。两头都要避免。

【流程和其他】
- 用中文回复。我不是技术人员，说清楚问题出在哪、打算怎么改，少用术语。
- 先做一段 10–15 秒的试点，确认画风和动作质量，再做全片。建议从开头对拳加标题、一段连续打斗、虚式茈里挑。
- 我不喜欢无休止地来回测试。交给我之前，你自己先逐帧看过关键时刻。
- 我指出哪里有问题，就只改那一处，我认可的部分不要动。
- 视频里不要加任何文字、署名、片尾卡，也不要加背景音乐，这些我自己来。
- GitHub 单个文件不能超过 100 MB，超过的请无损切段（pipeline/split.py 可以用）。
- 上一个会话的经验：这台云端机器会不定期重启，磁盘空间小，只有 CPU。长任务要能从断点续跑，中间文件及时清理。
```
