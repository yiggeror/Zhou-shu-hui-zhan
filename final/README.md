# 两个完整版（1080p60，约 97.4 秒，无音轨）

两版都按原片的时间轴（96 秒版）逐帧对应，切点、节奏和镜头都与原片一致。唯一的改动是每次命中定格 3 帧，所以总长比 96 秒多约 1.4 秒。视频里没有加任何文字或署名。

| 版本 | 文件 | 画面来源 |
|---|---|---|
| A：AI 重绘完整版 | `remake_redrawn_vfx/remake_redrawn_vfx_1080p60_part*.mp4` | Astra 的 518 张清晰原画，跟随原片测得的动作。约 4.5% 的画面没有能对上姿势的原画，这部分改用 v4 那套跟随原片动作的画面，避免停顿卡顿。 |
| B：原片增强特效版 | `original_vfx_enhanced/original_vfx_enhanced_1080p60_part*.mp4` | 原片全分辨率逐帧处理：去压缩噪点、线条锐化、轻微提亮。水印保留，因为两种去除方法都会留下字形残影。 |

**分段说明**：超过 100 MB 的文件在关键帧处无损切开，没有重新编码。已逐帧校验，拼接后与完整文件一致。按 `*_parts.txt` 的顺序播放即可，也可以用下面的命令拼回完整文件：

`ffmpeg -f concat -safe 0 -i remake_redrawn_vfx_1080p60_parts.txt -c copy full.mp4`

**特效**（两版相同，脚本是 `scripts/fxall2.py`）：
- **放在哪里**：逐个镜头检查后决定，对应脚本里的 `EYES` / `ENERGY` 表。天空、红色或蓝色的背景、血迹都不加粒子，也没有满屏飘的余烬。
- **眼睛**（五条是蓝色，宿傩是红色，共 41 个镜头）：
  - 发光光晕和白热的眼芯；
  - 横向镜头光条，轻微闪烁；
  - 眼睛移动时拖出光痕。
  - 眼睛检测在 `scripts/eyedet.py`，按“小而亮的光点，周围带蓝色或红色”来找。
- **攻击**：
  - 咒力拳：燃烧流动、残影拖尾、照亮周围。
  - 命中：闪光、双色冲击帧、冲击波、命中点星芒、放射速度线、闪电、震屏、推镜；火花集中在命中点附近。
  - 连击的处理会减弱。
- **赫、苍**：光球旋转，周围有环绕光点。
- **虚式·茈**（32.3–34.4 秒，以及 88.5 秒到结尾）：
  - 赫和苍两颗光球互相环绕、靠拢，合成紫光。
  - 原片过曝的白色改为紫色光：只有中心是粉白色，往外渐变成深紫；高光压在不爆白的范围内。
  - 不用白闪，几乎不加辉光。
  - 结尾的白屏和淡出也改成紫光。
- **其他**：本来就很亮的画面基本不加辉光。

**脚本**（`scripts/`）：
- `baseA60.py`、`baseB60.py`：生成两版在 60 fps 时间轴上的底片。
- `fxall2.py`、`eyedet.py`：特效。
- `finish.sh`：拼接、编码、分段。
