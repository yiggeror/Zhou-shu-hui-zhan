# 两个完整版（1080p60，约 97.4 秒，无音轨）

两版都按原片的时间轴（96 秒版）逐帧对应，切点、节奏和镜头都与原片一致。唯一的改动是每次命中定格 3 帧，所以总长比 96 秒多约 1.4 秒。视频里没有加任何文字或署名。

| 版本 | 文件 | 画面来源 |
|---|---|---|
| A：AI 重绘完整版 | `remake_redrawn_vfx/remake_redrawn_vfx_1080p60_part*.mp4` | Astra 的 518 张清晰原画，跟随原片测得的动作。约 4.5% 的画面没有能对上姿势的原画，这部分改用 v4 那套跟随原片动作的画面，避免停顿卡顿。 |
| B：原片增强特效版 | `original_vfx_enhanced/original_vfx_enhanced_1080p60_part*.mp4` | 原片全分辨率逐帧处理：去压缩噪点、线条锐化、轻微提亮。虚式茈的两个爆炸镜头（33.9–34.4 秒、91.9–93.9 秒）改用重绘画面，比原片清楚、不过曝。水印保留，因为去除后会留下字形残影。 |

**分段说明**：超过 100 MB 的文件在关键帧处无损切开，没有重新编码。已逐帧校验，拼接后与完整文件一致。按 `*_parts.txt` 的顺序播放即可，也可以用下面的命令拼回完整文件：

`ffmpeg -f concat -safe 0 -i remake_redrawn_vfx_1080p60_parts.txt -c copy full.mp4`

**特效**：两版相同，按逐镜头分镜表 `特效分镜表.md` 来加。每个镜头加什么由人决定，程序只负责在镜头里找到拳头、眼睛、球的位置，不会自己决定加不加。
- **咒力拳**：拳头上的咒力像火焰一样扭动、照亮周围，挥动时留下残影，并冒出余烬。
- **眼睛**：
  - 有张力的特写（如镜头 5、14、16、17、96）：眼中咒力，眼睛发光，眼睛周围有粒子往上飘；
  - 其他镜头：柔和发光。
  - 不加光条。
- **赫、苍**：球旋转，有光环、环绕粒子和电弧。
- **虚式茈**：
  - 赫和苍互相环绕，在五条手上汇合成紫光；
  - 爆炸时有紫色电弧、从核心飞出的火花和冲击波；
  - 高光平滑压缩，不会变成一片死白；命中用紫闪，不用白闪。
- **命中**：闪光、双色冲击帧、冲击波、放射速度线、闪电、火花、震屏、推镜。
- **其他**：伏魔御厨子、赫、终段爆炸有上升余烬；法轮有脉冲波；硬切有轻微闪光。

**脚本**（`scripts/`）：
- `baseA60.py`、`baseB60.py`：生成两版在 60 fps 时间轴上的底片。
- `fxall4.py`：特效与分镜表。
- `eyedet.py`：找眼睛。
- `finish.sh`：拼接、编码、分段。
