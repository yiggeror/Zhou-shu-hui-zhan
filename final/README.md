**特效**：按逐镜头分镜表 `特效分镜表.md` 来加。每个镜头加什么由人决定，程序只负责在镜头里找到拳头、眼睛、球的位置，不会自己决定加不加。
- **开头**：
  - 对拳：两拳交汇处有红蓝电弧和交汇光。
  - 标题：每个字落下时有紫色脉冲、色散和轻微震动；标题完成时有冲击环，白边上有扫光，红色滴落会发光。
- **宿傩**：
  - 躺着、脸上出现红纹（约 9.5–10.8 秒）：红纹发光，冒出细碎的咒力火花。
  - 起身（11–13 秒）：背后红幕轻微燃烧。
- **咒力拳**：拳头上的咒力像火焰一样扭动、照亮周围，挥动时有残影，并冒出余烬。
- **眼睛**：
  - 镜头 5、19（五条睁眼、宿傩红眼特写）：眼睛发光，眼中有细碎火焰，粒子收在眼里，不往外散。
  - 镜头 14、17、66、106、122：只把眼睛本身轻微提亮，不加光球和粒子。镜头 14 随睁眼渐亮；镜头 17 是剪影，切进剪影那一帧，前一个镜头的特效立即消失。
  - 镜头 6：眼睛微微发亮，偶尔有一两颗很小的火星停在眼睛上，不往外飘。
  - 镜头 16、56、123：手动定位眼睛，加发光和贴着眼睛往上燃烧的咒力火焰，跟着眼睛一起动。
  - 其他有张力的特写：眼中咒力；其余镜头：柔和发光。
- **赫、苍**：在球清楚可见的镜头（指尖上的赫、后面那颗大苍）里，手动定位球心和大小，只让球本身旋转，加贴着球的光环、环绕粒子和电弧；快速甩动、糊掉的镜头不加。
- **虚式茈**：
  - 蓄力：手中紫光汇聚并有电弧。
  - 最后合一：只给原片里赫和苍两颗球加光晕，以及沿它们自身轨迹的光尾；两球靠近时有电弧，汇合处出现紫光。不另画球。
  - 爆炸：高光平滑压缩，不会变成一片死白；电弧和火花只出现在爆炸镜头里，不会出现在脸上；命中用紫闪，不用白闪。
- **命中**：闪光、双色冲击帧、冲击波、放射速度线、闪电、火花、震屏、推镜。
- **其他**：伏魔御厨子和赫的镜头有上升余烬；法轮有脉冲波；硬切有轻微闪光。

**脚本**（`scripts/`）：
- `baseA60.py`、`baseB60.py`：生成两版在 60 fps 时间轴上的底片。
- `fxall7.py`：特效与分镜表（音乐剪辑时间轴，画面取自原版）。
- `align_yt.py`、`prep_yt.py`：把录屏的每张画对齐到 YouTube 原版的对应帧，并生成 1080p 底片。
- `tmap.npy`：音乐剪辑时间轴（输出时间 → 96 秒原片时间）。
- `eyedet.py`：找眼睛。
- `finish.sh`：拼接、编码、分段。
