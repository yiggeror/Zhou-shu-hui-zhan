# 试片 v2：特效跟着原片的运动走

v1 的问题是"静态图 + 切镜头"，没有连续运动；漩涡和片名都是突然切过去的。v2 换了底层：

**底层是连续运动。** 每一帧都是用 Astra 的清晰关键帧按原片测得的运动场（光流链）变形出来的，而且可以在原片任意两帧**之间**取值（亚帧插值：运动场、置信度、光照一起插值）。所以可以自由变速——慢动作、碰拳瞬间超慢放、转场处快速甩过——画面始终在动，不会卡成定格。

**特效锚定在运动物体上。**

- 火焰只长在正在移动的拳头能量区域上，余像拖在运动方向后面；余烬从拳头上脱落。
- 碰拳的冲击点取自两只拳头的实际接触位置：白闪、红黑冲击帧、冲击波、闪电、火花都从这里炸开。
- 拉远时，画面按实测速度场"脱落"成十几万个粒子，粒子继续被原片的运动带着走，再被卷进青、红两个对转的星系。
- 片名阶段：左边的青色星系流进左边的字（呪術），右边的红色星系流进右边的字（廻戦），逐字点燃。
  - 每个字落定时，换成 Astra 原画里那个字自己的清晰像素，并迸出火花。
  - 四个字齐了以后，一道光环从片名中心扩散，揭开整张背景。
  - 粒子目标、字、背景用的是同一个镜头矩阵（缓慢推近），所以不可能出现"双影"。
- 收尾：原片用黑色碎片合拢收尾，这里改成程序化的锐利黑色刀片依次斩入，刀口带光，直到全黑。

**不再有"异常模糊"。** 片名和结尾不再使用补出来的碎片帧。画面里剩下的模糊只有两种，都是刻意设计、随运动方向的：速度线和甩镜的运动模糊、光晕。
