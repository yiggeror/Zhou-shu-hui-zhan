# 试片 v1（开场 11 秒）

新方向的试验：不再逐像素跟随原片，而是理解原片的动作与节奏后，用清晰原画 + 镜头运动 + 程序化特效重新演绎。画面里的模糊都是刻意设计的动态效果，不是数据不足造成的。

| 文件 | 说明 |
|---|---|
| `pilot_clean_1080p60.mp4` / `pilot_clean_720p60_preview.mp4` | 原画风 + 特效 |
| `pilot_neon_1080p60.mp4` / `pilot_neon_720p60_preview.mp4` | 霓虹线稿风 + 特效 |

段落：青色火星点燃 → 青拳（程序化火焰燃烧、余烬、蓄力震屏）→ 黑白冲击帧 → 红拳（热浪）→ 放射速度线甩镜 → 俯拍逼近（电弧）→ 碰拳（白闪、红黑反相冲击帧、冲击波、青红闪电、火花、色散）→ 急速拉远 → 画面碎成十几万粒子 → 青红双螺旋星系对转 → 粒子汇聚成「呪術廻戦」→ 片名。

`../fx.py` 是特效与风格化工具库（火焰噪声、粒子、冲击波、闪电、速度线、光晕、色散、冲击帧、霓虹线稿），`pilot.py` 是这段试片的时间线。素材为 Astra 的关键帧，未使用原片像素。
