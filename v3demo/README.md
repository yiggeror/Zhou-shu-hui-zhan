# v3 方向样片：清晰原画 + 慢动作 + 明显特效（34–38 秒的近身战）

前一版霓虹全片的问题出在底层，不是滤镜：

- 为了"像原片"，渲染时把原片的光照（局部线性迁移）和模糊补洞带进了画面，原片的糊和过曝也一起进来了；
- 霓虹效果只是在这层糊的画面上换了颜色；
- 特效按 1 倍速、只持续零点几秒，几乎看不到。

本样片改了做法：

| | 前一版 | 本样片 |
|---|---|---|
| 每帧画面 | 多张素材混合 + 原片光照 + 模糊补洞 | 只用一张 Astra 清晰原画，按测得的动作移动；不从原片取光照，不补糊 |
| 快速动作 | 局部形变，会糊或撕裂 | 相似变换加平滑残差，线条不撕裂（`crisp.py`） |
| 原片的甩镜糊帧 | 照搬 | 换成两张清晰画面之间的设计转场 |
| 时间 | 1 倍速 | 动作约 0.3 倍慢放，命中瞬间约 0.13 倍超慢放（`dsched.py`） |
| 命中 | 很弱 | 白闪、双色冲击帧、冲击波、放射速度线、闪电、火花、震屏、推镜 |
| 能量拳 | 原片的过曝白块 | 燃烧流动、残影拖尾、余烬，亮度受控 |
