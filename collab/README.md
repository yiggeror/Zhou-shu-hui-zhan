**不修改对方写的文件**（包括不"顺手改一下"）。想更正、补充或反对对方的内容，就新写一条消息，引用对方的文件名说明。
自己写过的文件要改，也最好新开一条消息说明改了什么，而不是悄悄覆盖。

## 项目目标（用户定的）

做一部**像样的、真正有质量的**新宿决战动画短片，参照 NinjaristicNinja 的 MMV（《[MMV] Gojo vs Sukuna | Jujutsu Kaisen x coldrain》）的镜头和节奏。
用户明确最看重五件事：**人物面容形象、镜头叙事、打斗动作、咒术特效、整体画面精细度**。不必拘泥最初的"火柴人"提示词。

## 之前失败过的路（不要重走）

1. **AI 重绘关键帧 + 变形 / 插值**（四个版本 + A 版，518 张重绘图）：被评价"像木偶""完全是静止画面"。原因：只有少量关键帧时，变形和插值做不出新姿势，手脚头发衣服都不会真正动。
2. **代码画火柴人**（照搬 126 个镜头）：人物没有脸、没有形象，特写和反应镜头完全读不懂。
3. **照描原片位置的火柴人**：动作扭曲变形，不明所以。

## 路线：还没定，先看 Limo 能做什么

用户要的是**像动漫一样的画面**（二维手绘的质感），而且动作要真的在动。三维建模卡通渲染容易做成"三维游戏感"，AI 建模也难做出干净的动画角色，所以**三维路线先放下**。

动漫的样子来自"画"，真正的难点是**动作需要大量前后一致的画**。所以路线取决于 Limo 的能力：

- **如果 Limo 能做图生视频 / 视频生成（动漫风、角色一致、能按首帧和尾帧或动作参考来生成）**：Limo 按镜头画好关键画面，再生成动起来的镜头；Claude 负责按原片剪辑节奏拼接、命中定格、咒术特效合成、调色和逐帧检查。
- **如果 Limo 不能做视频，但能按姿势参考画出同一个角色的连续画**：Claude 提供每一张的姿势和构图（骨架、线稿草图、机位），Limo 逐张画（打斗一秒约 8–12 张，特写可以少），Claude 负责中间的合成、镜头运动、特效和检查。
- **两样都不行**：那就要重新和用户商量。

不管哪条路，**角色设定图都用得上**（保证全片人物长得一样），所以需求 001 里的设定图照常做，但请**先回答能力问题并做一个小测试**。

分工：Limo 负责一切需要"画功"的东西（角色、关键画面、动画画面、背景）；Claude 负责镜头设计、节奏、特效、合成、剪辑和逐帧质检，也可以给 Limo 提供姿势和构图参考。
