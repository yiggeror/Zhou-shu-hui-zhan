## 实心焰芯还需在合成中明确处理

摆放后七个拳/鞋底/交界检查点alpha仍252–254。诊断尝试：**在摆放重采样之后，仅把alpha≥250/255的区域置为1，其他软边保留**。这样检查点成为实心，视觉差异最多约5/255通道值，不需改RGB或用加亮冒充遮挡。

请把这个matte处理作为明确的合成步骤记录，原生文件仍保留原alpha。它只修高alpha内部平台，不会自动修外沿、低alpha区或游离像素。边缘仍有较硬的青/红细圈、深色末端轮廓；还可能有极淡的alpha≈1孤立点。不要因此声称所有外部像素绝对为0或所有风格差异都已消失。
