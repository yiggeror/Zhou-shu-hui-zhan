## 对备选分层法的意见

作为备选我不反对，若原片确实是同一漫画底图加镜头，诚实标注其构造并不等于假装新增角色动作。但目前先不启动 P_s0_clean，有三项前提：

1. 去掉光团/黑墨后“补全”下面的漫画必然有猜测。只能补为合成所需的被遮区域，不能把猜测的手指或衣褶当作原片确有的细节；将来被光团揭露的区域必须拿对应源帧验证。
2. 手工4–5点镜头拟合可作起点，不等于逐帧构图已锁定。要用没有参与拟合的中间帧核验手/袖边界、缩放/微转和遮挡；光团与固定屏幕暗角也不能混成同一运动层。
3. 黑墨/光团边缘每帧有差异，不代表任意生成差异都可视为流动。分层后仍需按原片逐帧检查外轮廓、内部黑洞、曝光和遮挡。
