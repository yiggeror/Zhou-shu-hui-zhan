## 3. 相对 047 预览的改动

1188–1191 和 1194 与 047 逐字节相同；1192、1193、1195 变了，原因如下。

**A. 白度场排除原片水印（你的代码卫生项）。**
- 原片 1192、1193 的水印框里，白度均值只有 0.833，周围是 1.000；模糊 40 px 后会留下一条淡暗带；
- 现在白度场在水印框内用周围的值填补（带权模糊），框内均值变为 1.000，然后才做模糊和拟合；
- 效果（感知亮度）：

  | 帧 | 047 框内 / 周围 | 现在框内 / 周围 |
  |---|---|---|
  | 1192 | 251.2 / 252.8 | 253.9 / 254.0 |
  | 1193 | 250.5 / 252.4 | 253.8 / 253.8 |

- 两参数拟合的描述按你的要求改为近似：遮罩强度取 0.02 间隔网格，场倍数用二分，在隔行隔列的像素上算。结果：
  - 1192：k = 0.593，c = 0.38，平均亮度 242.53（原片 242.43），白区 59.74%（原片 59.74%）；
  - 1193：k = 0.729，c = 0.24，平均亮度 223.21（原片 222.94），白区 35.81%（原片 35.81%）。

**B. 城市一拍二的曝光。** 先试了两种做法，都不好：
- 光照不变：每 2 帧一个台阶，跟不上原片逐帧变暗。1196 比原片暗 17.7，1199 亮 12.7，帧间变化差平均 5.5；
- 1201 用原片平均亮度比（0.723）整体乘：光球白芯被压成灰色，白区从原片的 4.1% 变成 0%。

**现在的做法**：
- 每个曝光用一条亮度曲线，在原片那一帧上拟合（亮度分布匹配，保持色比）；
- 白平衡每张画只用一套，取自这张画自己的源帧（K4 n1194、K2 n1197、C1198 n1198、K5 n1200），所以同一张画两次曝光颜色不变，只变明暗；
- 高光保护照旧，白芯保持白。

**结果**（原生 PNG 对原片，15 帧）：
- 平均亮度差：平均 0.69，最大 3.41（1196）；
- 帧间变化差：平均 0.90，最大 3.33；
- 1201：感知亮度 104.48（原片 103.44），白区 6.26%（原片 4.12%）。

**说明**：这是用原片那一帧的明暗分布去调另一视角的画，是曝光近似，不是同一内容的光照测量。来源表逐帧写明了每个曝光在哪一帧拟合、白平衡来自哪一帧。

## 4. 视频与原生的区别（`checks.md`）

- 编码带 `-sws_flags accurate_rnd+full_chroma_int`；
- 1190、1191 解码后只有 RGB [255,255,255]；
- 15 帧，24 fps，0.625 s，PTS 0 到 14/24；画幅 1672×942（原生 941，最后一行复制一次）。

**解码视频整体比原生 PNG 暗约 1.1–1.3 级**（例：1188 为 120.47 → 119.23）。我测了原因：
- 用无损 x264（`-qp 0`）只做 4:2:0 转换，也是 119.22；
- 纯灰色 128 往返后仍是 128.00；

所以是 4:2:0 色度下采样在饱和紫色上回到 RGB 时被截断，与压缩无关。近白面积在视频里也会变小（1192：PNG 59.74%，视频 41.69%）。数值基准以原生 PNG 为准，视频只看节奏。
