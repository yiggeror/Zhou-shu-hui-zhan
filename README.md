# Zhou-shu-hui-zhan

新宿决战木偶动画复刻：以用户上传的参考视频（96 秒变速版）为运动、节奏与运镜依据，用 Astra 生成的清晰关键状态图作为全部画面素材，逐帧重建。

当前版本（第 3 版）：
- 素材共 218 个关键状态：原资料包 159 个 + 补图 59 张（K001–K059，见 `keyframe_requests.md`）。
- **成片所有像素都来自 Astra 的素材图**，原片只用于测量运动、剪辑时间和光照（明暗、颜色的低频变化）。成片中不含原片像素，也没有水印或水印阴影的痕迹。

## 制作方法

`pipeline/` 下是完整制作脚本（不含原视频与素材包）。

1. **切点**（`decode.py`、`cutres.py`、`cuts2.py`）：解码参考视频（8298 帧，其中 3356 个不重复画面），用运动补偿残差把 126 个分析单元对位到精确切点。
2. **素材对位**（`register.py`、`registerK.py`、`sr.py`）：拆分 A/B 双状态图并去掉资料标签条，用 Real-ESRGAN（animevideo v3）做 2× 线稿超分，再用 SIFT + ECC 把每个状态精确对齐到它在原片中的取样帧。
3. **运动测量**（`pipe.py`、`stage1.py`、`stage1b.py`）：在每个镜头内，从每个锚点帧向前后逐帧链接稠密光流（带漂移校正，能跳过闪白/闪黑帧），得到每一帧相对锚点的形变场。原片水印的文字笔画及其阴影被排除在测量之外。
4. **逐帧重建**（`stage2.py`）：
   - 把清晰素材沿测得的形变场变形，并按局部速度加上与原片一致的运动模糊；
   - 用局部线性光照迁移还原闪光、能量光和色调变化；
   - 多个锚点按时间先验和匹配度混合，自动识别叠化转场并按拟合的比例交叉叠化；
   - 形变无法解释的区域，用同一素材沿运动方向生成的拖影填补。
5. **合成编码**（`assemble.py`、`split.py`）：按原片真实时间戳重采样到恒定 60 fps，保证每个切点、定格和闪帧落在原片的位置。

统计：按时长加权，平均每帧 81% 的区域是清晰素材直接变形的结果；61% 的帧 ≥80%。仍需靠拖影填补为主的画面约 11.5 秒（补图前为 18 秒），大多是闪白、强过曝和原片本身就重度运动模糊的帧。

## 已知局限

- 少数极短的闪帧没有对应素材，例如约 13.2 秒处手捂额头的红黑闪影、约 33.2 秒处紫光闪电推镜，播放时呈模糊的色块，每处约 0.05–0.1 秒。
- 素材是生图工具的重绘，个别细节（窗格、云纹、特效内部纹理）比原片更具体，这是素材本身的差异。
