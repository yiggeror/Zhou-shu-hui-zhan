## 第 4 版"动作捕捉复刻版"的做法

以 96 秒参考视频为运动、节奏和运镜依据，以 Astra 生成的清晰关键状态图为画面素材，逐帧重建。

- **素材**：253 个关键状态，包括原资料包 159 个和三轮补图（见 `keyframe_requests*.md`）。
- **像素来源**：成片所有像素都来自素材图，原片只用来测量运动、剪辑时间和光照，所以没有水印。
- **局限**：人物动作偏僵，打斗段落有卡顿。原因是少量关键帧靠变形做不出新的姿势，详见交接说明第 4 节。

制作步骤（`pipeline/`，不含原视频和素材包）：
1. **切点**（`decode.py`、`cutres.py`、`cuts2.py`）：解码参考视频，共 3356 个不重复画面，对出 126 个镜头的切点。
2. **素材对位**（`register*.py`、`sr.py`）：把素材做 2× 超分，再精确对齐到原片的取样帧。
3. **运动测量**（`pipe.py`、`stage1*.py`）：在每个镜头内逐帧链接稠密光流。原片水印不参与测量。
4. **逐帧重建**（`stage2.py`）：
   - 素材沿测得的形变场变形，并加上运动模糊；
   - 迁移光照；
   - 多个锚点之间做混合。
5. **合成编码**（`assemble.py`、`split.py`）：按原片时间戳重采样到 60 fps。
