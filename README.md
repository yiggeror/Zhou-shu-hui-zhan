# Zhou-shu-hui-zhan

新宿决战木偶动画复刻：以用户上传的参考视频（96 秒变速版）为运动、节奏与运镜依据，用 Astra 生成的 126 张/159 个清晰关键状态图作为画面素材，逐帧重建。

## 成片

| 文件 | 规格 |
|---|---|
| `output/1080p/` | 1920×1080，60 fps，H.264，96.000 秒（5760 帧） |
| `output/720p/` | 1280×720，60 fps，H.264，96.000 秒（5760 帧） |

- 无音轨：上传的参考视频本身是静音版。
- 画幅为原片主体的 16:9 画面（原录屏左右各约 268 px 的黑边未保留），镜头内部自带的上下黑边照原片保留。
- 超过 GitHub 单文件 100 MB 限制的版本按关键帧无损切段（`_part1`、`_part2`…，流复制、未重新编码）。已逐帧校验：各段按顺序拼接后，与完整编码的每一帧哈希完全一致，没有缺帧、重复帧或缝隙。
- 合并为单个文件（可选）：进入对应目录执行
  `ffmpeg -f concat -safe 0 -i <名称>_parts.txt -c copy 合并.mp4`

## 制作方法

`pipeline/` 下是完整制作脚本（不含原视频与素材包）。

1. **切点**（`decode.py`、`cutres.py`、`cuts2.py`）：解码参考视频（8298 帧，其中 3356 个不重复画面），用运动补偿残差把 126 个分析单元对位到精确切点。
2. **素材对位**（`register.py`、`sr.py`）：拆分 A/B 双状态图并去掉资料标签条，用 Real-ESRGAN（animevideo v3）做 2× 线稿超分，再用 SIFT + ECC 把每个状态精确对齐到它在原片中的取样帧。
3. **运动测量**（`pipe.py`、`stage1.py`、`stage1b.py`）：在每个镜头内，从每个锚点帧向前后逐帧链接稠密光流（带漂移校正，并能跳过闪白/闪黑帧），得到每一帧相对锚点的形变场。原片水印的文字笔画被排除在测量之外。
4. **逐帧重建**（`stage2.py`）：把清晰素材沿测得的形变场变形；用局部线性光照迁移还原闪光、能量光、色调变化；双状态镜头按时间和置信度混合；自动识别叠化转场并按拟合的比例交叉叠化。形变无法解释的区域（极快动作、换画、强曝光）平滑过渡为柔和的动态模糊。
5. **合成编码**（`assemble.py`、`split.py`）：按原片真实时间戳重采样到恒定 60 fps，保证每个切点、定格和闪帧落在原片的位置。

统计：平均每帧 77% 的像素直接来自清晰素材；57% 的帧 ≥80% 来自素材；81 帧为自动识别的叠化帧。

## 已知局限

- 素材只有 159 个关键状态，而原片有约 3356 个不同画面。原片中换画、高速挥击、强烈运动模糊的瞬间（约 12% 的帧），以柔和的动态模糊呈现，而不是清晰线稿。
- 素材是生图工具的重绘，个别细节（窗格、云纹、特效内部纹理）比原片更具体，这是素材本身的差异。
