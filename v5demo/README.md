# v5 样片：原速动作 + 清晰原画 + 命中特效（三段打斗）

`demo_v5_1080p60.mp4`：1080p60，约 25 秒，无音轨，CRF 18。三段是 34.4–42.1 秒（近身战、扔楼、斩线碎楼）、54.5–58.6 秒（近身战）、69.5–81.0 秒（近身战、红球、重拳、法轮、式神追击、楼间飞行），按 96 秒版计时。

**做法**

- **动作和镜头**：与原片逐帧一致，原速，切点、定格位置都和原片相同。唯一的改动是每次命中定格 3 帧（hit-stop）。
- **清晰度**（`scripts/crisp5.py`）：
  - 每帧只用一到两张清晰原画，按原片测得的动作移动；
  - 不再用模糊去补洞；
  - 光影只迁移大尺度的明暗（闪光、曝光）；
  - 原片自身运动模糊、测量不可靠的区域，原画保持刚性，不做局部扭曲。
- **60fps 插帧**（`scripts/crisp60.py`）：原片两张画之间按测得的运动连续移动同一张画（红球飞行等高速运动更顺）；下一帧对不上同一张画时不插值，原样停住，和原片一致。

**原片自带的运动模糊**：
- 原片整帧都是运动模糊、且画面在高速移动时（甩镜、红球飞行），按测得的运动方向，对清晰原画做方向性拖影，还原原片的速度感；
- 原片清楚或画面移动慢的地方，一律用清晰原画；
- 镜头开头和结尾、原片里纯甩镜过渡的帧，直接沿用 v4 的效果，和原片一致；
- 两张画只在对得上的地方混合，避免双影；
- 测量不可靠的区域整体刚性移动，不出现波纹。

**补图未覆盖的姿势**（`scripts/display.py`）：停在同镜头最近的一张清楚画上一到三帧，相当于动画里的"一拍二、一拍三"。实在没有可停的画，就只跟随镜头运动。
- **特效**（`scripts/fx5.py`）：
  - 每次命中：白闪、双色冲击帧、冲击波、放射速度线、闪电、火花、震屏、推镜；
  - 连击（间隔不到 0.15 秒）减弱处理；
  - 咒力火焰持续流动、残影拖尾、余烬；
  - 硬切处加轻微闪光和色散。

**素材**：原资料包、K001–K094，以及第三轮 265 张（必补 94 + 建议补 171，K095–K412，不含"可选"）。镜头内关键图很多时，每帧只取时间上最近的 4 张同镜头图和前后镜头各 1 张（`pipeline/basefrac.py` 的 `K_NEAR`），以控制内存。
