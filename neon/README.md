# 霓虹线稿版（全片）

用原片的场景、镜头和运动，重新演绎成霓虹线稿风格，并加入程序化特效、动效和转场。场景顺序和镜头内容都跟原片一致，新增的部分只是叠加在画面上的特效。

| 文件 | 规格 | 大小 |
|---|---|---|
| `neon_1080p60.mp4` | 1920×1080，60 fps，95.07 秒（5704 帧），无音轨 | 80.7 MB |
| `neon_720p60.mp4` | 1280×720，60 fps，95.07 秒，无音轨 | 45.5 MB |

带音乐的版本（视频与上面相同，音轨直接取自用户提供的《雨爱》剪辑）不放进仓库，单独发给用户。

## 卡点：时间轴取自用户的音乐剪辑

用户的音乐剪辑（95.07 秒）不是 96 秒参考版的匀速变速版本。两者是原片的两种不同变速，相对速度按段落在约 ×1.13 和 ×0.85 之间切换。所以本版的时间轴直接从那份剪辑测出来：

1. `match30.py`：把剪辑的每一帧（30 fps）和原片的 3356 个不重复画面做相关匹配。
2. `align.py`：用单调动态规划求出最优对应路径。
3. `tmap.py`：做稳健的局部线性平滑。结尾的白场到灰场到黑场按亮度曲线对齐。
4. 得到"输出时间 → 原片时间"的映射 `timing/tmap.npy`。

结果：

- 映射与匹配点的误差中位数为 10 ms。
- 125 个切点与剪辑中对应切点的差：中位数 0，90% 不超过 1 帧（剪辑本身是 30 fps）。
- 把《雨爱》直接对齐视频开头放上去，就和那份剪辑一样卡点，不需要再压缩或拉伸。
- `beats.py` 从同一音轨测出节拍（约 77 BPM）和鼓点重音，写入 `timing/beats.json`，用作画面上轻微的发光脉冲。

## 画面怎么做的

**底层是连续运动。** 每一帧都由 Astra 的清晰关键帧，按原片测得的形变场变形得到。取样时间是映射给出的任意时刻，可以落在原片两张画之间：

- 原片两张画之间的动作，用亚帧插值补出来，所以动作连贯，不会顿；
- 切点保持在原位。

**霓虹线稿**（`nstyle.py`）：

- 墨线和明亮的细线（斩线、裂纹、轮廓光）都转成发光线条，线条颜色取自局部颜色；
- 暗场先做局部对比度提升，让暗处的画也能出线；
- 亮区（闪白、白底）保留亮度，因为这些闪光本身就在节拍上；
- 高饱和的光（咒力、光球、天光）保留成发光的色块。

**自动特效**（`fxfull.py`，每帧根据画面内容生成）：

- 能量区域会流动燃烧（噪声位移），并沿运动方向甩出余烬；
- 移动的线条留下霓虹光迹，静止的线条不留；
- 每个切点都有转场修饰，而且以切点那一帧为中心，切点本身的时间不变：
  - 硬切：数字故障（切片错位加 RGB 分离）；
  - 白闪：保留并加强白闪；
  - 红黑闪切：双色冲击帧加震屏；
  - 甩镜：沿运动方向的速度线和拖影；
  - 叠化：光晕脉冲。

**关键时刻**（`events.json`）：

| 片段 | 效果 |
|---|---|
| 开场碰拳 | 白闪、红色冲击帧、冲击波、闪电、火花 |
| 片名 | 字出现的瞬间迸出火花 |
| 茈 | 蓄力时的电弧、白闪爆发、楼体爆炸冲击波 |
| 红球 | 环绕粒子、爆炸 |
| 重拳 | 冲击帧加黑红电弧 |
| 法轮 | 扩散光环 |
| 苍 | 反向环绕粒子、释放爆发 |
| 红色天幕 | 上升余烬 |
| 结尾紫爆 | 大冲击波和粒子 |

**片尾卡。** 剪辑最后约 1.9 秒是黑场，这里加了一个霓虹「呪術廻戦」片尾卡，并注明原作者。

## 脚本

| 脚本 | 作用 |
|---|---|
| `scripts/basefull.py` | 按 `tmap` 渲染连续运动底层，依赖 `../pipeline/basefrac.py` |
| `scripts/nstyle.py` | 霓虹线稿风格 |
| `scripts/events.py` | 生成事件表 |
| `scripts/fxfull.py` | 风格化加全部特效，按镜头并行 |
| `scripts/encode.sh` | 编码；轻度时域降噪去掉逐帧胶片颗粒，保留线条 |
